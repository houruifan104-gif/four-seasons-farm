# 四季田园

一款受《农场主》（Agricola）启发的原创单人网页策略游戏。你与 1–5 名电脑对手轮流派工，经营 14 轮，在第 4、7、9、11、13、14 轮收获后结算。

## 运行

[在线游玩](https://houruifan104-gif.github.io/four-seasons-farm/)，支持手机与电脑。网站由 GitHub Pages 从 `main` 分支根目录自动发布。

可直接打开 `play.html` 离线游玩。也可以在本目录运行 `python3 -m http.server 8000`，打开 `http://localhost:8000`。点击“新游戏”选择人数、沼泽、四季、外星人与卡牌模式。进度保存在当前浏览器。

## 基础玩法

- 每位家庭成员每轮派工一次，每个普通行动格每轮只可被一人使用。
- 资源行动格每轮累积，派工时拿走格子里的全部资源。
- 开田、播种、扩建和围牧场需要在农场棋盘选格子。
- 收获时田地产物、牲畜繁殖、喂养家人。每人消耗 2 食物，短缺转为乞讨标记。
- 有空房才能扩员；新成员从下一轮起增加派工次数。

## 扩展模式

### 沼泽农夫

- 农场初始有 5 片森林、3 片泥沼。伐木移除森林得木材，切泥炭移除泥沼得燃料，刀耕火种可将森林变成田地。
- 特殊行动不消耗家庭成员。同一特殊行动每轮最多使用两次；第二位使用者需付 2 食物。
- 马可饲养、繁殖与计分。普通灶台不能烹饪马，需马肉厨房或对应设施。
- 每次收获还要给房屋供暖：木屋每间需 1 燃料；黏土屋总费用减 1，石屋减 2。木材可 1:1 代替燃料。缺燃料会让家人卧床，下轮必须去医务所。
- 泥炭窑、护林屋、马肉厨房，以及房屋材料升级可供选择。

### 5/6 人

- 新游戏可选最多 6 人，目前为 1 位玩家加电脑对手。
- 5/6 人局加入小树林、河岸林、树林、土坑、旅人、资源市场和牲畜市场等行动；6 人局再加入农具补给、资源交易、畜栏、副业与额外小设施。

### 职业与小设施

- “学习职业”“小型设施”会打出手牌，支付对应费用并持续生效。开局每人有 4 张职业与 4 张小设施。
- 本作的可玩手牌仍是 8 张职业、8 张小设施的原创精简牌组。
- 页首“原版牌库”可检索 15 周年版 A/B 牌组的 336 张卡号和英文名称（168 职业、168 次要发展），并打开对应的在线资料页。目录仅供查阅，不参与发牌或自动结算。
- 目录数据位于 `card-catalog.js`，可用 `python3 scripts/import_catalog.py` 更新；不包含原卡图像或卡面文字。A113 在主目录缺失，名称从修订版卡牌汇编补齐。

### 四季流转

- 春夏秋冬逐轮交替，各有一个行动格。资源累积、开田、围栏、烘焙、收获和扩员会随季节改变。
- 可与沼泽农夫、职业设施、外星人扩展同时开启。

### 外星人 X 卡

- 第 5 轮起，派人到采石场时翻开一张卡。牌堆共 24 张，包含公共行动、商人、神器、事件和职业。
- 已翻开的卡及其效果显示在右侧“外星人扩展”。一些复杂效果已按本作的精简棋盘改编，例如糖果、绑架、冻结与怪圈。

### 主要发展

- 10 张公共主要发展卡含壁炉、烹饪灶台、水井、烤炉及三种工坊。每张只能由一位玩家建造。材料、烹饪、面包、食物收入和结算分数会生效。

## 与官方规则的关系

这是独立设计的精简改编，包含主要扩展机制，**不是官方规则与所有卡牌的逐项还原**。牧场容量、建筑费用、卡牌效果、行动格和计分采用了适合本电子版的简化实现。不使用原作卡面图像或逐字文案。原版 336 张职业与次要发展目前只有名称目录，效果尚未实现。
